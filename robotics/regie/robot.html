  1. 1. Position de repos
    Coupe la raideur, place la chaîne à la main dans sa position de repos, puis capture.
  2. 2. Position de départ
    Place la chaîne dans la position d'où partent tous les gestes, puis capture.
  3. 3. Plages
    Démarre, balaie à la main toute la zone permise pour chaque articulation, puis arrête.
  4. 4. Vitesse
    Fraction de la vitesse max des moteurs (bornée par le robot).
  5. 5. Rejeu de validation
    Le robot joue repos → départ → min et max de chaque articulation → départ → repos.
  6. 6. Fin
    Enregistrer écrit le profil sur le robot (après un rejeu). Annuler garde l'ancien.
